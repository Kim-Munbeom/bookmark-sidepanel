# Bookmark Sidepanel

Chrome Side Panel API로 북마크를 조회/검색/편집하는 확장 프로그램입니다.
네이티브 세로 탭과 유사한 사용성을 목표로 하며, 상세 설계는
`docs/specs/2026-09-14-bookmark-sidepanel-design.md`를 참고하세요.

## 설치 (개발자 모드)

1. `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" → 이 폴더 선택
4. 툴바 아이콘 클릭으로 사이드패널 열기/닫기

## 사이드패널을 왼쪽으로 이동

Chrome 설정 → 모양 → 사이드패널 → 왼쪽으로 변경 (확장 프로그램이 아닌 Chrome 자체 설정입니다).

## 사용법 및 동작 확인

확장 프로그램을 로드한 뒤 아래 항목을 순서대로 확인하세요.

1. 툴바 아이콘 클릭 → 사이드패널이 열리고 실제 Chrome 북마크(북마크바, 기타 북마크 등)와 트리 구조가 일치하는지 `chrome://bookmarks`와 비교
2. 폴더 제목 클릭 → 펼침(▾)/접힘(▸) 토글 확인
3. 검색창에 북마크 제목/URL 일부 입력 → 해당 북마크만 표시되는지, 없는 문자열 입력 시 "검색 결과가 없습니다." 표시되는지 확인
4. 아무 웹사이트를 열고 "+ 현재 탭" 클릭 → `chrome://bookmarks`에 추가됐는지 확인
5. 북마크 삭제 버튼 클릭 → `chrome://bookmarks`에서도 사라지는지 확인 (북마크바/기타 북마크/모바일 북마크 같은 최상위 폴더에는 삭제 버튼이 없는 것도 정상입니다)
6. 북마크를 다른 폴더로, 그리고 같은 폴더 안의 다른 위치로 드래그앤드롭 → `chrome://bookmarks`에서 실제로 이동/재정렬되는지 확인. **위/아래 양방향 모두** 확인하세요 — 드래그 방향에 따라 대상 바로 앞/뒤 배치가 의도와 다를 수 있습니다
7. Chrome 설정에서 사이드패널을 왼쪽으로 이동 후, 패널 안쪽 경계를 드래그해 폭 조절 → 페이지 콘텐츠가 실제로 줄어드는지(오버레이가 아닌지), 320px 아래로는 줄지 않는지 확인
8. Chrome을 완전히 재시작 → 패널이 자동으로 열리지 않는 것(예상된 동작), 아이콘 클릭 시 다시 열리는 것을 확인

## 알려진 제약

- 브라우저를 재시작하면 사이드패널이 자동으로 열리지 않습니다. 툴바 아이콘을 한 번 클릭해야 합니다. (Chrome 플랫폼 제약, 우회 불가)
- 사이드패널 최소 폭은 약 320px이며 이 아래로 줄일 수 없습니다.
- 폭을 조절해도 브라우저 재시작 시 기본값(약 360px)으로 초기화됩니다.
- 아이콘은 임시 플레이스홀더입니다 (`icons/`). 배포 전 교체가 필요합니다.

## 아직 지원하지 않는 기능 (v1 범위 밖)

- UI 커스터마이징 설정 화면 (색상, 폰트 크기 등)
- 폴더 펼침 상태의 영구 저장
