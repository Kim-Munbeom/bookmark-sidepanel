# 백로그

v1 구현 및 최종 리뷰 과정에서 발견했지만 지금 당장 고치지 않기로 한 항목들.

## 회귀 (최종 리뷰에서 발견, 미수정)

- **예약 루트 폴더(북마크바/기타 북마크/모바일 북마크)에 드래그로 직접 넣기 불가**
  최종 리뷰에서 "예약 루트 폴더의 삭제 버튼"을 막는 수정을 하면서, 그 폴더 헤더에 드롭하는 기능까지 같이 없어짐.
  지금은 해당 폴더에 북마크가 하나라도 있으면 그 위로 드롭해서 넣을 수 있고, 완전히 비어있을 때만 "+현재 탭"(북마크바) 또는 `chrome://bookmarks`(기타/모바일 북마크)로 우회해야 함.
  고치려면: `attachDragHandlers`를 드래그 소스용(`dragstart`)과 드롭 대상용(`dragover`/`dragleave`/`drop`)으로 분리해서, 예약 루트 폴더는 드롭 대상 리스너만 유지하도록 수정.

## 사소한 항목 (Minor)

- 삭제 버튼의 `event.stopPropagation()`이 죽은 코드 — Task 5에서 클릭 핸들러 위치를 옮기면서 막을 대상이 없어짐. 무해하지만 나중에 행 전체 클릭을 다시 붙이면 헷갈릴 수 있음.
- 웹페이지에서 링크/텍스트를 패널로 드래그하면 내부 북마크 id가 아닌 문자열이 넘어와 "이동 실패" 에러만 뜸. 내부 드래그 전용 MIME 타입을 쓰거나 드롭 시 id 유효성 검사를 추가하면 깔끔해짐.
- 드래그를 Esc로 취소하면 `.drag-over` 점선 테두리가 남을 수 있음 (`dragend`에서 전역 정리 안 함).
- 북마크 변경 이벤트마다 전체 트리를 재조회/재렌더 — 대량 임포트/정리 시 다수의 리렌더 발생 가능. v1 규모에서는 문제 없음, 필요해지면 디바운스 추가.
- 키보드 접근성 없음 (마우스/포인터 전용, `tabindex`/`role`/Enter 처리 없음).
